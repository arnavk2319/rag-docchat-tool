# AI design

| Decision | Choice | Why (one line) | Cost impact |
| -------- | ------ | -------------- | ----------- |
| Generation model | Hosted `claude-sonnet-5-5` (agent/answer), `claude-haiku-5-5` (map/grade/compress/groundedness); Ollama optional (T-018; best-effort for tool calling, small local models are unreliable at it); ids in config only | Best tool calling; cheap tier for sub-steps | <= $0.05/agent request, <= $0.02/20-page summary; tests $0 (mock) |
| Embedding model | `all-MiniLM-L6-v2` via sentence-transformers, local, loaded once by the registry (`core/models.py`, id from `EMBED_MODEL`) | Free, fast on CPU, good enough for recall@5 >= 0.8 | $0 API; ~0.1 GB RAM |
| Vector store | Embedded Chroma PersistentClient + `rank-bm25` index | No server, metadata filter by doc_id/owner | $0; single-process only |
| Chunking | parent-child (T-009): child ~300 tok (~1200 chars) embedded, parent ~1200 tok (~4800 chars) returned as context; breaks on paragraph/sentence/whitespace; page/sheet/section + char offsets; tokens approximated as chars/4 | Precise match, rich context, exact citation spans | $0; slightly larger index |
| Retrieval (top-k / hybrid / rerank) | BM25 + dense top 20 each, RRF fuse (k=60, built T-010; top-k 5 default from the request), `bge-reranker-base` (registry, id from `RERANK_MODEL`) to top 5; abstain if top rerank score < `MIN_RERANK_SCORE` (default 0.0 is a PLACEHOLDER: real bge logits can be negative, so it is untuned both ways; built T-011; env var must be added to `.env.example` by a human) | Hybrid catches keywords and semantics; rerank lifts precision; abstention prevents hallucination | $0 API; ~1.1 GB RAM, +200-500 ms CPU |
| Agent loop / tools | LangGraph (T-016 built): router (fast) -> plan (agent) <-> tool -> answer (agent); grade/rewrite/groundedness come later; 6 read-only allow-listed tools; SSE later. Bounds: `recursion_limit`=AGENT_MAX_STEPS (8) node runs, per-run Budget 30k tokens + AGENT_MAX_USD ($0.05) which also absorbs LLM calls inside summarize/compare; max_tokens clamped to remaining budget, call skipped if USD cannot cover it | Spec P3; structured, streamable, bounded | Max 8 steps and $0.05 per run; Haiku for router/grade/groundedness |
| Guardrails | Retrieved text and tool output as delimited data; doc_id scoping; per-run step/token/USD caps; rate limit + daily USD cap; PII-free logs; groundedness check | Mitigates indirect injection and runaway spend | Small extra Haiku call per answer (~$0.001) |
| Summarization | Map-reduce (T-012): parent texts packed into <= `SUMMARY_BATCH_CHARS` (8000) batches, `fast` map to <= 4-sentence partials, reduce (role `SUMMARY_REDUCE_ROLE`, default `fast`) to <= 8 sentences, hierarchical collapse when partials exceed one batch; sha256 + prompt-version cache; `Budget` cap `SUMMARY_MAX_USD` 0.02 returns a partial result (`partial: true`) | Covers the whole document (v1 truncated at 24000 chars) at Haiku prices | ~$0.005-0.02 per 20-page document; repeat call $0 |
| Compression | Optional (`SUMMARY_COMPRESS`, off by default): `fast` LLM keeps only relevant passages of each batch before map (`prompts/compress.md`); extractive top-n sentence fallback on empty/NONE/error | Cuts map input tokens on boilerplate-heavy docs; fallback keeps it deterministic | One extra Haiku call per batch when on; counts against the same cap |
| Wrapper limits | One `llm.complete()`: 30 s timeout, 3 retries (429/5xx/timeout, backoff + jitter), per-run `Budget` (steps/tokens/USD), 1 JSON repair retry; details in `docs/architecture/llm.md` | Single choke point for cost, safety and mock tests | Caps runaway spend; no retry on 4xx |
| Price table | `config.prices` USD/1M tokens in/out: sonnet-5-5 3.00/15.00, haiku-5-5 1.00/5.00; unknown ids cost 0 | Per-call USD logging and budget enforcement; update when prices change | Logging only; no extra cost |

## Prompts
Versioned files in `prompts/*.md` (header: id, version, model_tier, updated), loaded by `core/prompts.py`; never inline strings.
- `answer` v1 (agent tier; renamed from `query`, used by `/v1/query`): single-shot answer from retrieved excerpts. Excerpts go inside `<excerpt id source>` tags, the question inside `<question>`; both are escaped (`<`, `>` -> entities) so retrieved text cannot close a tag. The prompt states the tagged text is DATA, tells the model to say "I don't know." when the excerpts lack the answer and to cite excerpt ids.
- `summarize` v2 (fast tier): the legacy single-shot prompt, no longer used by `/summarize` (superseded by the map/reduce prompts below).
- `summarize_map` v1, `summarize_reduce` v1, `compress` v1 (fast tier): text goes inside `<section>`, `<partials>`, `<passage>` tags, angle brackets escaped, DATA rule stated (T-012).
