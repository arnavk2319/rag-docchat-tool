## Acceptance
- [x] H1 upload limiter: POST /v1/documents is limited per `tenant:user` (default 5 uploads/hour, env `UPLOAD_RATE_PER_HOUR`); over limit returns 429 `rate_limited` with `Retry-After`. Test.
- [x] H1 per-owner cap: an `anon-` owner may hold at most `ANON_MAX_DOCS` (default 5) documents; the upload beyond it is rejected per file with a fixed error code (add to ADR-0002 codes list and openapi). Non-anon owners are unaffected (`SESSION_MAX_PER_OWNER`-style default, env). Test both.
- [x] H1 demo-tenant byte cap: total stored bytes for the demo tenant capped by `DEMO_TENANT_MAX_BYTES` (default 200 MB); upload over it is rejected with a fixed code. Test.
- [x] H1 ingest concurrency: at most `INGEST_MAX_CONCURRENT` (default 2) ingests run at once; extra requests wait or get 429 (pick one, document). Test.
- [x] M1 global mint limiter: POST /v1/auth/anonymous also has a global per-hour bucket (default 200, env `ANON_MINT_GLOBAL_PER_HOUR`) on top of the per-IP one; a per-IP-exempt flood cannot exceed it. `docs/deploy.md` documents TRUSTED_PROXY (which header, exactly one trusted hop, origin must not be publicly reachable). Test.
- [x] M3: failure_reason and upload error detail returned to clients never contain a raw exception class name; unknown exceptions map to fixed `ingest_failed` (full class still logged). Test with a parser that raises a custom exception.
- [x] L1: middleware adds `X-Content-Type-Options: nosniff` and `Cache-Control: no-store` to all /v1 responses (not SSE-breaking). Test.
- [x] L2: `json_body_limit` (64 KB) applied to compare and doc-intel routes. Test: oversize body returns 413.
- [x] Remove `/ping-checkpoint` (main.py) and any test referencing it.
- [x] `docs/openapi.json` regenerated, drift test green, `docs/architecture/security.md` updated, `uv run ruff check . && uv run pytest -q` pass; no paid API call (mock mode).

Contract as built: upload limiter counts one slot per POST /v1/documents request (not per file), key tenant:user. New per-file codes `doc_limit_reached`, `storage_limit_reached` (HTTP 200 body, not in the all-validation-failed 413/415 set). Ingest concurrency: waits on a semaphore (chosen over 429). Global mint 429 code `global_rate_limited`. Re-uploading bytes the owner already holds is exempt from quotas. Non-anon owners: `OWNER_MAX_DOCS` default 200 (0 = unlimited).
Edge cases: quota checks are not transactional (concurrent uploads can overshoot by a few files). Byte cap sums tenant docs via registry.list_older_than (limit 100000). Cache-Control: route-set value (SSE no-cache) is kept; nosniff always set.
Known gaps: limiter/gate are per-process (1 replica). Pre-existing documents rows with class-name failure_reason are masked on read, not rewritten.
New env vars (human adds to .env.example): UPLOAD_RATE_PER_HOUR=5, ANON_MAX_DOCS=5, OWNER_MAX_DOCS=200, DEMO_TENANT_MAX_BYTES=209715200, INGEST_MAX_CONCURRENT=2, ANON_MINT_GLOBAL_PER_HOUR=200.
