## Findings (implementer)
Files changed: vectorstore/{base,memory,pgvector_store,sync,__init__}.py (added `get_chunks`/`list_chunks`, `SyncVectors` sync tenant-bound view + `Hit`, chunk ids may contain `:`/`.`); store/{bm25,registry,sessions,pg}.py; services/{ingestion,retrieval}.py; main.py, api/deps.py, core/{config,models}.py; new app/db/migrate.py + migrations/0001_init.sql; evals/run.py; pyproject.toml + uv.lock (chromadb removed, no new deps); store/chroma.py deleted; tests updated (+ test_registry_store, test_session_store, test_migrate, vecutil).
Contract as built: `VectorStore` (async, tenant-scoped) is the only vector backend. Ingestion takes it directly (`tenant_id` default "default"); retrieval/tools use `SyncVectors(store)` (hops to the app loop via anyio from worker threads, `asyncio.run` fallback in tests/evals). `Registry` (existing Protocol) now has InMemory/Sqlite/Postgres impls; new `SessionStore` Protocol with InMemory/Sqlite/Postgres. Postgres repos are sync (psycopg_pool.ConnectionPool, called via run_blocking), bound to one tenant, every statement filters tenant_id+owner_id. BM25 is in-memory only; `hybrid_search` rebuilds an owner's index lazily from stored chunk text (`rebuild_bm25`) when `has_owner` is False; ingestion/delete keep it current. Deviation from ADR s2: no `bm25_docs` blob table, because chunk text in `vector_chunks` is the single source and re-tokenising is cheap. Without `DATABASE_URL` the app runs fully in-memory (registry, sessions, vectors; warns); with it, Postgres. Parents store is still SQLite at DB_PATH (not in this ticket's scope). `python -m app.db.migrate` applies `migrations/*.sql`, refuses hosts other than localhost/127.0.0.1/db unless a human sets MIGRATE_ALLOW_REMOTE=1; never run by this ticket. `FakeEmbedder` now zero-pads to 384 dims (cosine unchanged).
Edge cases: empty doc_ids = no results; foreign owner/tenant = None/False; k clamped to 200 in SyncVectors; cancelled ingest still purges (async `_fail`).
Known gaps: `.env.example` still lists CHROMA_DIR (human-only file; replace with DATABASE_URL, DB_POOL_MAX); Postgres repos tested only with a recording fake pool (no live DB; add an opt-in integration test); BM25 is per-process so a second replica sees new docs only after restart; parents still SQLite; tenant is fixed to "default" until T-029; `docs/ai-design.md` Chroma lines need a human/doc pass.
Eval (mock) before vs after, identical: recall@5 0.7857, mrr 0.75, citation_correct 0.7647, task_success 0.75 (all four were already below thresholds before this ticket; no regression). Run with `PYTHONPATH=tests uv run python -m evals.run --mock` (test_injection imports `authutil`).
Verify: `uv run ruff check . && uv run pytest -q` -> 992 passed, 5 skipped. Chroma grep and `grep -r migrate scripts .github` print nothing.
