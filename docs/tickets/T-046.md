## Findings (implementer)
Shapes (docs/openapi.json, 200): POST /v1/documents/{doc_id}/summary (no body) -> DocSummaryResponse {doc_id, summary, citations[], partial, abstained}; /sentiment -> DocSentimentResponse {doc_id, label (free string), confidence 0..1, rationale, citations[], partial, abstained}; POST /v1/compare {doc_ids (2..5), focus<=200} -> CompareResponse {doc_ids, similarities[], differences[] of ComparePoint {point, citations[]}, partial, abstained}. Errors: 404 not_found, 409 not_ready/document_busy, 429 rate_limited/spend_cap_exceeded/budget_exceeded, 502 llm_*.
Files: web/src/features/docintel/{flag,types,api,DocIntelView,docintel.test}.ts(x); web/src/{App,Shell,NotFound}.tsx; web/src/mocks/handlers.ts (separate docIntel block); web/src/test/xss.test.tsx; web/e2e/docintel.e2e.ts; web/package.json (build:e2e bakes VITE_FEATURE_DOC_INTEL=1); web/src/vite-env.d.ts.
Contract: flag via docIntelEnabled() (VITE_FEATURE_DOC_INTEL==='1'), read at router creation; off => /summary|/sentiment|/compare hit the new `*` NotFound route and no nav renders. Centre pane gets a Views nav (Chat/Summary/Sentiment/Compare) when on. Each run is an explicit button, disabled while running; summary/sentiment run sequentially over ticked ready docs and stop on 429 (rate_limited/spend_cap/budget), marking the rest "Not run"; compare needs 2..5. Citations use the shared CitationChips + SourcePane. Text (summary, rationale, compare points) goes through decodeEntities once (backend sanitize_output escapes & < > once) and is rendered as React text only; `label` is not decoded. Round 2: Chat stays mounted (hidden) under intel views, Chat nav link returns to /chat/:id, per-document loop aborts on unmount, NotFound uses Link.
Gaps: web/.env.example not editable by agents (denied): human adds `VITE_FEATURE_DOC_INTEL=` (0/1, default off; 1 enables /summary /sentiment /compare) and mirrors to root. Spec name e2e/docintel.spec.ts is docintel.e2e.ts here. Flag-off bundle still contains the doc-intel code (flag is a runtime function, not dead-code eliminated); routes are unreachable. Compare mock handler needs docs present in mock state (e2e uploads one).
