## Acceptance

- [ ] POST with no body returns 200 `{access_token, token_type:"bearer", expires_at}`; each call mints a distinct `owner_id` under the configured demo tenant (test)
- [ ] TTL comes from env `ANON_TOKEN_TTL_SECONDS` (default 3600); a token past `expires_at` is rejected (test with frozen clock)
- [ ] Per-IP mint rate limit: N+1th mint in the window returns 429 `{detail, code:"rate_limited"}`; IP read from the trusted-proxy header only when `TRUSTED_PROXY` is set, else the socket peer (test both)
- [ ] Demo-tenant caps: anonymous owners are subject to per-user and demo-tenant daily USD caps (`ANON_USER_DAILY_USD_CAP`, tenant cap from T-029); exceeding returns 429 `spend_cap_exceeded` (test)
- [ ] 401 bodies keep `{detail, code}`: expired token -> `token_expired`, malformed/bad signature/unknown -> `invalid_token` (test both)
- [ ] Minted tokens cannot reach another owner's documents or sessions (isolation test)
- [ ] No token value appears in logs (caplog test)
