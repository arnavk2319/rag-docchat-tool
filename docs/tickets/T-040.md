## Findings (implementer)
Files: web/src/features/documents/{DocumentsPanel.tsx,UploadErrors.tsx,hooks.ts,validate.ts,DocumentsPanel.test.tsx}; web/src/pages/Documents.tsx (standalone wrapper with own QueryClient + local selection state).
Contract: `DocumentsPanel({selected,onToggle,onSelectAll,onClear,pollMs?})`; hooks `useDocuments(pollMs)`, `useUploadDocuments`, `useRemoveDocument` (alias `useDeleteDocument`). All/None -> onSelectAll(readyIds)/onClear. Delete of a selected doc calls onToggle(id) on success.
Edge cases: >10 files sends first 10, rest listed as errors plus alert; 413/415 all-failed `{results}` bodies parsed as per-file errors; optimistic delete rolled back on error (document_busy shown under row); polls only while pending/processing.
Gaps: the shared "selection consumed by Chat" store is T-041's (not built here, per ownership rule). Documents page has its own QueryClientProvider; T-041 shell should provide one and drop it. jsdom FormData loses filenames over Node fetch, so tests stub upload responses.
Deferral: the store consumed by Chat and the shared QueryClientProvider are deferred to T-041 (acceptance line added there). Round 2 added polling-stops, list-error and 'Already uploaded' (deduplicated) note tests.
