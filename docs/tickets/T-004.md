- [ ] (deferred from T-003) `utilities/file_handler.py` loaders raise a typed `ParseError` instead of swallowing exceptions and returning None; no `print` and no model loading at import time; `utilities/setup.py` import-time model loading is removed (the registry replaces it); tests assert a corrupt file raises `ParseError` and importing the module has no side effects.
