## Acceptance
- [ ] Routers in `api/`: `POST /documents`, `GET /documents`, `DELETE /documents/{doc_id}`, `POST /summarize`, `POST /query`; `X-User-Id` header required via dependency (missing -> 401). `uv run pytest -q tests/test_api.py` covers each with TestClient + mock LLM.
- [ ] Cross-user access to a doc_id returns 404 (test).
- [ ] `/query` does single-shot retrieve (dense only) + mock LLM answer, returns `{answer, citations[]}` with Citation fields per spec; `/summarize` returns `{summary, doc_id}` via `fast` role.
- [ ] Old `routers/`, `utilities/` removed; `grep -rn "chromadb.HttpClient\|langchain" src` returns nothing.
- [ ] Request/response Pydantic models (one per entity) appear in `/openapi.json` (test checks paths).
- [ ] `docs/architecture/api.md` written (endpoints, auth header, errors); overview updated.
- [ ] (ADR-0002, supersedes path/shape wording above) routes live under `/v1`: `POST /v1/documents` (multipart `files`, up to 10 files, 10 MB each, 50 MB per request; always 200 with per-file `UploadResult{ok, doc_id, status, deduplicated, error{code, detail}}`; ingestion runs synchronously in the request), `GET /v1/documents` (paginated `limit`/`offset`, returns `total`), `GET /v1/documents/{doc_id}`, `DELETE /v1/documents/{doc_id}` (204; 404 for other owners, never 403; 409 `document_busy` while ingesting), `POST /v1/summarize` (`doc_id` or `doc_ids`, exactly one; returns `{summary, doc_ids}`), `POST /v1/query` (`{question, doc_ids?, top_k?, session_id?, stream?}` -> `{answer, citations[], abstained, session_id?}`; sessions and streaming bodies are accepted but handled in T-020/T-019). Error bodies are `{detail, code}`; `BudgetExceeded` -> 429, `LLMTransportError` -> 502 `llm_unavailable`, `LLMValidationError` -> 502 `llm_bad_output`.
- [ ] (ADR-0002) `X-User-Id` dependency `current_user`: missing/blank -> 401 `auth_required`; over 64 chars or outside `[A-Za-z0-9_.@-]` -> 401 `invalid_user_id`; tests use `dependency_overrides`.
- [ ] (ADR-0002) registry gains a nullable `documents.failure_reason` column with `user_version` 2 (idempotent migration from version 1 covered by a test opening a version-1 database); ingestion stores the failure code there; upload results and GET expose it.
- [ ] (ADR-0002, T-003/T-004 properties preserved) legacy `routers/response.py` and `/validate-upload` are deleted; its sniffing, zip limits, streamed 10 MB cap and temp-file cleanup move unchanged into `api/uploads.py` / `core/security.py` with their tests still passing.
