## Findings (implementer)
Files: new `src/backend/app/services/docintel.py`, `src/backend/app/api/docintel.py`, `prompts/summary.md`, `prompts/sentiment.md`, `tests/test_doc_intel.py`; edited `api/schemas.py` (DocSummaryResponse, DocSentimentResponse), `main.py` (router include only), `evals/{run.py,metrics.py,thresholds.json,golden.jsonl,results.json}`, `tests/test_evals.py` (counts).
Contract: `POST /v1/documents/{doc_id}/summary` -> {doc_id, summary, citations[Citation], abstained, partial}; `/sentiment` -> {doc_id, label positive|negative|neutral|mixed|unclear, confidence, rationale, citations, abstained, partial}. One `fast` llm.complete call each with schema validation; model returns section indexes, citations are built server-side from parent records (cannot be forged); invalid/no indexes fall back to leading sections shown. Auth, per-user+global rate limit, user/tenant/global daily spend lease reuse `SummarizeLease` (summary_max_usd). Unknown/foreign/other-tenant doc -> 404, not ready -> 409.
Edge cases: < 8 words or model `insufficient`/unknown label -> abstained, "I don't know.", no citations (weak docs make no LLM call). Text capped at 16000 chars -> partial=true. Section text goes through sanitize_untrusted; output through sanitize_output.
Eval: 12 inline-text items (10 scored + 2 abstain) appended to golden.jsonl (types summary/sentiment; `load_golden` still returns the 20 agent items). Mock: citation_present 1.0 (>=0.95), sentiment_label_accuracy 1.0 (>=0.80), recorded under `doc_intel` (with `_label: mock`) in thresholds.json. Mock lexicon stand-in proves wiring, not quality.
Known gaps: pre-existing `evals.run --mock --check` failures recall_at_5/citation_correct/task_success (identical in committed results.json before this ticket) - untouched. Summary here is single-call over capped text (no map-reduce); long docs are partial. evals.run now adds tests/ to sys.path so the injection suite imports under `python -m`.
Env vars: none new. See it: `uv run pytest tests/test_doc_intel.py -q`; `uv run python -m evals.run --mock`.
