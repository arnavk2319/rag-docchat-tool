- [ ] `docs/architecture/api.md` documents SSE event schema; `docs/architecture/overview.md` updated for agent flow.
- [ ] (ADR-0002) SSE event names are `step`, `tool_call`, `tool_result`, `token`, `citations`, `final`, `error` (the single `tool` event in the original wording is replaced by `tool_call` + `tool_result`); every payload carries `run_id` and `seq`; `: ping` heartbeat every 15 s; client disconnect cancels the graph task; budget stops arrive as `final.stopped_reason`, not a 500. ## Findings (implementer)
- Files: `api/sse.py` (new), `api/query.py` (stream branch after doc resolution, `-> Any`), `services/agent/graph.py` (`run_agent(run_id=, on_event=)`, node wrapper emitting step/tool events), `services/agent/nodes.py` (`Deps.emit` field only), `tests/test_sse.py` (new), `tests/test_api.py` (old "stream ignored" test narrowed to session_id), `docs/architecture/api.md`, `overview.md`.
- Contract as built: ADR-0002 section 4 event table. Agent emits raw events (no seq); sse.py sanitises (fixed step labels, validated args with doc ids limited to caller scope, `tool_result` = ok + n_items only), escapes `<>&` in answer/tokens/filenames, numbers them. Bounds and citation logic untouched; hook is per-run (Deps), None = no-op.
- Edge cases: no ready docs -> stream of token/citations/final(abstained) without a run; llm_error -> `error` then `final(error)`; budget -> `max_usd` if usd >= cap else `max_tokens`; unhandled -> `error internal` + final.
- Known gaps: stream citations are doc-level `{doc_id, filename, span}` (agent core has no chunk ids); tokens are chunked after the full answer (no model streaming); disconnect poll granularity 1 s (generator close cancels immediately); `top_k` and `session_id` ignored in stream mode; table_loader unwired.
- Hardening: `sanitize(step)` allow-lists `node` (unknown -> "step", empty summary). Audit: tool names allow-listed, filenames/spans/answer/tokens/args escaped, stopped_reason and error code/detail from fixed sets, doc ids limited to caller scope.
- See it: `uv run pytest -q tests/test_sse.py`; curl -N -X POST /v1/query -H 'X-User-Id: u' -d '{"question":"..","stream":true}'.
## Tests (test-writer)
- Added `tests/test_sse_extra.py` (15 tests, mock LLM / faked run_agent, no paid calls): strict frame parsing (2-line frames, one-line JSON, no CR) with newline/`data:`/`event:` injection in answer, filename, span, tool args; seq 1..n and run_id constant per run, distinct across runs and 5 concurrent streams; event order for tool run and direct reply; tool_result only ok/n_items; unknown tool/foreign doc ids dropped; foreign citations dropped; max_steps/max_tokens/max_usd/unhandled-error finals with fixed strings; 401/422/404 JSON before stream; no filename leak across owners; no-ready-docs abstains without running agent; generator close cancels with no further LLM calls or leaked tasks; `: ping` is a comment and consumes no seq.
- BUG (strict xfail `test_step_node_is_allow_listed`): `sanitize("step")` echoes `node` unescaped in `api/sse.py`. JSON-safe (no frame forgery) but violates the escape rule; only reachable if a node name is attacker-controlled (currently fixed internal names). Fix: allow-list against STEP_SUMMARY.
