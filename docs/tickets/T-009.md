## Findings (implementer)
- Files: src/backend/app/services/chunking.py (pure), services/parent_lookup.py, store/parents.py (new); services/ingestion.py; tests/test_chunking.py (new); docs/architecture/{chunking,ingestion}.md, docs/ai-design.md.
- Contract: `chunk_document(pages, doc_id) -> list[ParentChunk]` (children nested). ids: parent `<doc>:<p>`, child `<doc>:<p>:<c>`. Targets: child 1200 chars, parent 4800 (tokens ~ chars/4, no tokenizer, constants in chunking.py). Chunks are non-overlapping, trimmed; offsets slice page text exactly. `chunk_pages(...)` in ingestion now returns `(parents, children)`.
- Storage: Chroma holds children only; parents in SQLite table `parents` in the registry DB file (SqliteParents, owner-scoped, PK (owner_id, parent_id), indexes). `IngestionService(registry, store, embedder, parents=None)` derives the DB path from the registry. Parents purged on delete/fail/cancel/re-ingest.
- `expand_to_parents(owner_id, child_hits, parents)` -> `ParentHit(parent, best_child_id, distance, score)`; deduped, best-child order.
- Existing tests changed (forced by the new chunk id/return format): test_ingestion_extra.py chunking tests rewritten; test_ingestion.py fixed-window overlap test replaced by a whitespace-only test.
- Edge cases: sheets skip heading detection; section carries across pages; whitespace-only docs -> empty_document.
- Gaps: heading heuristics are simple (numbered list items without trailing period may read as headings); no overlap between chunks; existing indexes from T-006 (old ids) are not migrated (re-ingest needed).
- Heading heuristic tightened (round 1): numbered headings need a 1-2 digit number (dotted/`)`/`Section N`) + capitalised title; <=80 chars, <=12 words, no trailing sentence punctuation.
- Review round 1: section lookup now bisect on per-page sorted heading offsets (200k-heading page well under 3 s; regression tests vs a linear reference; pathological long lines tested); public `SqliteRegistry.db_path`, no getattr fallback; shared `store/sqlite.py` helper.
- Docs ticket note: documents ingested before T-009 (old ids, no parents) must be re-ingested; they degrade safely (no results, no errors).
- See it: `uv run pytest -q tests/test_chunking.py`.
