## Acceptance
- [ ] `uv run pytest tests/test_chunk_passage.py -q` passes: owner gets `{doc_id, chunk_id, filename, page?, sheet?, text, highlight{start,end}}` where `text` is the parent passage (capped at 4000 chars) containing the chunk and `highlight` are offsets into `text` of the cited chunk, `0 <= start < end <= len(text)`

- [ ] `docs/openapi.json` regenerated and includes the route and schema; `docs/architecture/api.md` documents it; `uv run pytest -q` passes
## Findings (implementer)
- Files: api/documents.py (route), api/schemas.py (Highlight, ChunkPassage), tests/test_chunk_passage.py, docs/openapi.json, docs/architecture/api.md.
- Contract: doc via registry (owner+tenant), chunk via tenant-scoped vector store `get`, parent via tenant-scoped parents; all misses 404 `not_found`. highlight = chunk offsets minus parent char_start; if parent > 4000 chars the text is windowed to keep the chunk; if offsets are unusable it falls back to locating chunk text, else whole text.
- Gaps: chunk longer than 4000 chars is clipped (highlight end clamped). Verified: ruff clean, full pytest 1111 passed.
