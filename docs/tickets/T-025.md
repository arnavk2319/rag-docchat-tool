## Findings (implementer)
- Files: src/backend/app/vectorstore/{__init__,base,memory,pgvector_store}.py; docker-compose.yml; tests/test_vector_store.py, tests/test_pgvector_store.py; pyproject.toml (+uv.lock): deps psycopg[binary]==3.2.9, psycopg-pool==3.2.6, pgvector==0.4.1, boto3==1.38.0 (all resolved at the ADR pins) and the `integration` pytest marker.
- Contract: Protocol `VectorStore` with upsert_chunks / query / delete_doc / count per ADR-0003 s1. tenant_id and owner_id are mandatory; ids must match ^[A-Za-z0-9_-]{1,64}$ (ValueError otherwise); embeddings 384-d; k in 1..200. query returns ScoredChunk(chunk_id, doc_id, text, metadata, score=cosine similarity). delete_doc returns the number of rows deleted; count(tenant, owner=None, doc=None).
- PgVectorStore takes an AsyncConnectionPool-like object. Table `vector_chunks` (DDL in `SCHEMA_SQL`, HNSW vector_cosine_ops). Values are always bound parameters; vectors are sent as text cast with ::vector, so no type registration is needed. The only string formatting is a fixed SQL fragment for the optional doc filter. The migration file and runner belong to a later ticket; the integration test applies SCHEMA_SQL itself.
- Edge cases: empty doc_ids returns [] without touching the DB; the integration test refuses a non-local DATABASE_URL.
- Known gaps: the Pg impl was not run against a real DB (none available here). The ADR status is still "proposed"; the acceptance path `docs/decisions/ADR-0003-*.md` is really docs/decisions/ADR-0003-*.md. Nothing is wired into retrieval yet (Chroma remains until a later ticket).
- Human-only: add to .env.example `DATABASE_URL=postgresql://docchat:<password>@localhost:5432/docchat` (secret; local compose only), and `POSTGRES_PASSWORD` (required by docker-compose.yml; optional `POSTGRES_USER`, `POSTGRES_DB`, default docchat).
- See it: `POSTGRES_PASSWORD=x docker compose up -d db`, then `DATABASE_URL=postgresql://docchat:x@localhost:5432/docchat uv run pytest -m integration`. Verify: uv run ruff check . && uv run pytest -q -> 955 passed, 5 skipped.
