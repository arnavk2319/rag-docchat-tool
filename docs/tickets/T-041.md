## Findings (implementer)
Files: web/src/api/{sse.ts,text.ts}(+tests), web/src/{Shell.tsx,useNarrow.ts,App.tsx}, web/src/features/chat/*, features/source/SourcePane.tsx, features/scope/{ScopeContext,storage,LeftPaneDocuments}. pages/Chat.tsx removed; pages/Documents.tsx left unused for T-040.
Contract: `streamQuery(q, signal)` async generator of validated StreamEvent (throws ApiError pre-stream, StreamIncompleteError if no final; abort ends quietly). Backend `<>&"'` entities decoded in the reducer (api/text.ts), rendered as text nodes only. Chat state is a local useReducer. Scope store: useScope() {selected, docs, nameOf, toggle, selectAll(ids), clear, refreshDocs}; per-session persistence via sessionStorage `docchat.scope` (ScopeProvider sessionId prop; hook for T-042). Left pane = T-040 DocumentsPanel fed from useScope(); one QueryClientProvider in web/src/AppProviders.tsx; ScopeProvider derives docs/nameOf from useDocuments() (no own fetch, no refreshDocs). pages/Documents.tsx and the placeholder were removed. Max question length 2000 chars (client constant, backend has none documented).
Edge cases: stop reasons max_tokens/max_usd have separate budget labels; user Stop shows "Stopped by you"; unknown/malformed frames dropped.
Known gaps: /documents and /chat both render the same shell (/documents opens the Documents tab on narrow); no Conversations list yet (T-042); session_id is not returned by stream so first answer does not create a route.
Round 3: ScopeProvider derives `selected` as ready-only ids once a document list has loaded (unprune while loading/erroring); stored per-session ids are loaded at first mount and pruned the same way. SourcePane slices highlight by code points (Array.from); invalid offsets render plain text. Filename in SourcePane is NOT entity-decoded: api.md says the chunk endpoint returns raw JSON data (only stream events escape `< > &`), so decoding would corrupt names containing `&`.
